# Judge Brave — The Ferryman

A single quiet scene for the make.fun bounty "Make the AI judge feel brave":
an old ferryman unties his rope the same way each morning, though the river
runs high and the fog hides the far bank. He does not hurry. He checks the
knot once, steps aboard, and the boat slips out slow and steady into the
white, carrying nothing but the day.

`main.ts` (Node 22, stdlib only) writes that text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` — deterministic, byte-identical every run.
